One line roasting a fridge's ice maker: it makes three cubes, sighs, and clocks out — the laziest appliance in the kitchen, and the only one with a union rep and a pension plan.

> My fridge's ice maker makes three cubes, sighs, and clocks out — the only appliance in my kitchen with a union rep and a pension plan.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), exactly the line and nothing else.
